    OptionalinstanceId

    instanceId?: number

    A number that tells the instances of one class apart, e.g. 3. It is assigned when an instance first makes a request or, while a method cache observer is set, first has a call answered from the method cache. It is unique within the process across all classes, but can differ in the next run, so do not key a recording on it.
